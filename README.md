# ByRoLaba10 — Проект интерфейса программной системы

Лабораторная работа S2G11 по ТРПО, вариант 3 — **«Графический редактор»** (ByRo Paint).
Исполнитель: Быстряков Р. К., группа ИКТС-2512.

## Что внутри

| Путь | Что это |
|---|---|
| `ByRoLaba10_Proekt_interfeysa.pdf` | **Итоговый отчёт** — все материалы в векторном PDF |

| `src/content.html` | Текст отчёта (ТЗ, исследование, сценарии, стилистика…) |
| `src/*.js` | Генераторы векторных макетов: иконки, компоненты UI-кита, экраны, диаграммы |
| `svg/` | Все макеты и диаграммы отдельными SVG-файлами (можно импортировать в Figma) |
| `tokens.json` | Дизайн-токены (цвета тем, шрифты, отступы) для разработчиков |

## Как пересобрать PDF

Нужны Node.js и Microsoft Edge (или Chrome):

```
node src/build.js   # отчёт

```

> Макеты сделаны не в Figma (доступа не было), а как векторные SVG из единого набора компонентов и токенов.
> Любой файл из `svg/` можно перетащить в Figma — он откроется как редактируемые слои.
